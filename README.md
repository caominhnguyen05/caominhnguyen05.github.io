# Cao Minh Nguyen — Portfolio

Hi, this is the project for my personal portfolio website, which I built with Next.js, React, TypeScript, and Tailwind CSS.

The website shows my projects, working experience, education, and skill set. Feel free to reach out if you want to connect! 

[Portfolio website](https://caominhnguyen05.github.io/)

## Run locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000). On Windows PowerShell, use `npm.cmd` if script execution is restricted.

Development uses `.next-dev/`; production builds use `.next/`. Keeping these generated folders separate prevents a production build from replacing files used by an active development preview.

## Repository structure

- `src/app/`: page, layout, global styles, portfolio sections, and content data.
- `src/components/ui/`: reusable UI components.
- `src/lib/`: shared utilities.
- `public/`: images, project screenshots, logos, and résumé.
- `tests/`: browser tests and static preview server.
- `docs/`: project documentation.
